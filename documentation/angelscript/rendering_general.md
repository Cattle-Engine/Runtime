# CE::Graphics

## Functions
### SetClearColour
Return type: `void`

Signature:
```angelscript
const Colour& in colour
```

Sets the background colour for 2D rendering, and when a skybox face is missing

### SetRenderResolution
Return type: `void`

Signature:
```angelscript
CE::Window::WindowSize& in size, CE::TextureFilter filter
```

Sets the renderer resolution, so you can have a 1920x1080 window with a small pixel art render size
